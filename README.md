# Paraply Interactive Tribute

This project is an interactive homage to [Paraply.org](https://paraply.org/), a Swedish organization. It was created with Paraply's consent.

## Tools

| Tool | Implementation |
| --- | --- |
| Astro | Structures the pages and components, and handles the project build and assets. |
| GSAP | Drives the animated sequences, transitions, and timing throughout the experience. |
| GSAP ScrollTrigger | Connects animation progress to scrolling, pins scenes, and controls when each sequence can advance. |
| Three.js | Renders the cinematic 3D environment, including the street, character, rain, fog, lighting, and wet surfaces. |
| Postprocessing | Adds visual effects such as bloom, tone mapping, vignette, and film grain on supported devices. |
| Canvas 2D | Renders effects such as the water-text reveal, lightning flash, rain, and umbrella splash collisions. |
| TypeScript | Implements the interaction logic, animation controllers, and performance adaptations. |
| CSS | Handles responsive layouts, typography, masks, fades, and atmospheric compositing. |
| Sharp and WebP | Optimize image assets while preserving their visual quality. |
